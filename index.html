What the evidence pack covers

Method

We do not collapse unlike provider roles into a single “market rate.”

ROLE → CURRENTNESS → DENOMINATOR → PAYMENT → ACTUAL EXPENSE → TERM → EXIT → GOVERNANCE → REALIZED OUTCOMES → NON-COMPARABILITY → SOURCES
